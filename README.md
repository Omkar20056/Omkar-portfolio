# Omkar Bhekane — Personal Portfolio

Responsive animated dark-theme portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
Extract the ZIP and open `index.html` in your browser.

## Customize
- Replace the `OB` initials avatar with your own photo if desired.
- Add your completed projects with real GitHub and live-demo links.
- Add only verified achievements and certificates, with credential links where available.
- Keep the skills list accurate as your experience grows.

## Publish using GitHub Pages
1. Create a new GitHub repository, e.g. `omkar-portfolio`.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
5. GitHub will display the published website URL in the Pages section.

Contact links are prefilled with the GitHub, LinkedIn and email details supplied for this portfolio.
