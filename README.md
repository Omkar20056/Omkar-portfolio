## Run locally

1. Clone this repository.
2. Open the folder in VS Code.
3. Start a local static server (for example, VS Code Live Server) and open `index.html`.

The Supabase-backed dynamic project and certificate sections require the public Supabase project configuration in `supabase-config.js`. The public client key is designed for browser use with appropriate Row Level Security policies. Never put a Supabase `service_role` key or other server secret in frontend code.

## Publish with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Select **Deploy from a branch**.
3. Choose the `main` branch and `/(root)`.
4. Save and wait for the Pages deployment to finish.
